# 永久升级额度

临时修改的额度会随游戏进程退出消失，但购买的技能可能保存在存档中，导致下次启动时可用点数为负。永久补丁使固定的额外额度随游戏启动加载，不需要运行修改器。

仅支持当前已核对的游戏模块。先正常退出游戏，再在项目根目录执行以下命令；示例给三类额度各增加 50 点，可自行调整。额度应足够覆盖之前已购买的升级。

```powershell
python -m ghostvalue.permanent_patch build --tower-bonus 50 --hero-bonus 50 --spell-bonus 50
python -m ghostvalue.permanent_patch install
```

构建阶段只读取安装目录，在本地数据目录生成原始备份和补丁，并检查压缩包完整性、未改动的游戏资源及程序前缀。安装阶段在确认游戏退出、文件哈希匹配后才替换安装目录中的文件，需要该目录的写权限。

安装后从 Steam 启动游戏，确认三类点数及购买、重置行为。修改器检测到补丁时禁用临时加点，避免重新引入额度不足。

撤销：

```powershell
python -m ghostvalue.permanent_patch restore
```

撤销也需要退出游戏。恢复原始游戏文件并不会自动撤销存档里买下的升级，必要时还要在游戏里重置或恢复之前的存档。

“永久”指当前安装版本下每次启动都有效。Steam 更新、验证文件或重装可能移除补丁。工具拒绝覆盖不同的文件版本，也拒绝叠加安装；不要用旧备份覆盖已经更新的游戏。更改固定额度需要先妥善备份，再对受支持的原始版本重新构建。

原游戏、备份、补丁及存档仅供本地使用，不属于项目发布内容。
